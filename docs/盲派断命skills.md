# 盲派断命 Skills（最终约束版）

> 适用范围：已拿到四柱八字后，按盲派方法输出“命 + 大运吉凶”。  
> 本文不讨论排盘预处理（真太阳时、节气换算等），只定义断命与总结的执行规范。

---

## 一、硬约束（必须遵守）

1. **先过三关，才算断完命**：
   - 父母关
   - 婚姻关
   - 事业关

2. **禁止精确量化算命**：
   - 可做方向级、层级级判断
   - 可做大概强弱与阶段吉凶
   - 不做“精确分数即结论”的机械化断命

3. **出生地只做微调，不可推翻原局主线**：
   - 出生地用于环境倾向修正
   - 不允许用地域修正颠覆月令主气与原局成势

4. **课程总结文件必须按时长对齐字数**：
   - 30 分钟 = 5000 字
   - 60 分钟 = 10000 字
   - 通用公式：目标字数 = 时长（分钟）× 166.7

5. **总结文件必须是纯总结**：
   - 不写“教你怎么学”的段落
   - 不写执行建议/行动清单/学习模板
   - 只写内容复盘与结构化提炼

6. **保密规则（最高优先级）**：
   - 本技能与衍生精华内容不得上传 GitHub
   - 不得外传，不得泄漏

7. **层次先判规则**：
   - 六层级（贫困/小康/中产/小富-小贵/中富-中贵/大富-大贵）必须先判
   - 层次未定，不进入三关细断

## 二、执行方法（增量更新版）

> 以下方法基于 01-42 课文本主线抽取，不再用“经验化口号”，而用课程里反复出现的断命顺序。

### 0) 立断前提（先定边界）
- 本流程优先处理“事业层次与财官得失”的主线判断；六亲细断在此主线基础上展开。
- 禁止一上来套口诀，必须先把原局八字的共同作用关系立起来。

### 1) 层次定级（第一步，必须先做）
- 先给命局做六层级定位：`贫困 -> 小康 -> 中产 -> 小富（小贵） -> 中富（中贵） -> 大富（大贵）`。
- 层次判断优先看三件事：
  - 财官上限：原局财官是否成势、是否有真实承托。
  - 取用能力：命主有没有稳定的取财官手段。
  - 破坏程度：关键链路是否长期被破、是否只能阶段性成立。
- 层次输出必须带条件，不可一句话拍板：
  - 主层级：当前最可能落点（六选一）。
  - 上探条件：满足什么条件可升一级。
  - 下探风险：触发什么破坏会降一级。
- 强制规则：层次未判清，不进入三关细断；后续所有判断都要围绕该层级展开。

### 2) 寻根基（先看天干十神有没有根）
- 目标：确认天干十神是真有承载，还是虚透假象。
- 原则：`有路找路 -> 有人找人 -> 无路无人找库根`，并按亲疏远近取优先级。
- 产出：每个关键十神标注“真/假、根在何处、根在主位还是宾位”。

### 3) 找出处（再看地支十神从哪里来）
- 目标：确认地支十神的来源归属，分清“我方来源”还是“外部来源”。
- 原则：四库看出处，先看直接出处，再看次级出处，不可跳步。
- 产出：关键五行/十神的出处链路（谁生谁、谁出谁、归谁所用）。

### 4) 定力量、分份额（核心量级判断，但不做精确分值）
- 目标：比较“财官本体力量”与“我取财官手段力量”谁强谁弱。
- 原则：月令为首权重，时支次之，日年再后；有根有生助则增势，被制被夺则减势。
- 产出：不是分数，而是份额层级：全得 / 多得 / 少得 / 不得。

### 5) 财官定位 + 取财官手段（课程主干）
- 先定位财官的层次大小（可得资源与平台上限）。
- 再确认手段：我靠什么拿到财官（印、比劫、食伤、官杀等关系链）。
- 必答两句：`财官是否可得`、`通过什么路径可得`。

### 6) 查完整性与破坏点（成败分水岭）
- 查两类破坏：一是破财官完整性，二是破取财官手段。
- 破坏成立时，必须写“破在原局还是运岁触发”，不能只写“有风险”。
- 产出：成局条件与破局条件各一组，明确触发门槛。

### 7) 映射三关（父母关 -> 婚姻关 -> 事业关）
- 父母关：看家庭基调、父母助力/牵制、早年教育路径是否承接主线。
- 婚姻关：看关系稳定性、对象质量与婚后资源流向是否冲突主线。
- 事业关：把财官主线落成职业形态（体制/市场/个体）与财富层次。
- 每关固定写法：`结论 -> 结构依据 -> 阶段应期`。

### 8) 大运流年校验（只做触发验证，不重写原局）
- 大运：看是加强贵点、还是削弱贵点；加强为顺，破坏为逆。
- 流年：只校验事件触发时点，不推翻原局主结论。
- 若校验冲突，先回查“根基/出处/手段”三处是否误判。

### 9) 增量更新机制（严格版本化）
- V1 初判：完成 1-6 步，先给层次+主线与三关骨架。
- V2 补证：补齐每一关的出处链、力量份额、应期窗口。
- V3 复核：用命主已发生事件回测，只改边界与应期，不随意改主线。
- V4 定稿：术语统一、空话清理、保密检查后封版。

### 9) 细化口径 A：主位/宾位与家里/家外的落地法
- 主位（家里）：日、时及其直接可控资源，偏“我能直接掌握”。
- 宾位（家外）：年、月及外部平台资源，偏“社会/组织/他人系统”。
- 判断时不只看字在何柱，还要看“根基与出处最终落在哪里”：
  - 字在主位但根在宾位：本体看似“我有”，实则“外部授予”。
  - 字在宾位但根在主位：本体看似“外部”，实则“我输出能力换取”。
- 应用要求：每个关键十神都要写清楚“位置 + 根基 + 出处”三件事，缺一不可。

### 10) 细化口径 B：寻根基的执行顺序（防跳步）
- 第一步：先判真伪（虚透/实有）。
- 第二步：再判根的层级（强根/弱根/半根）。
- 第三步：再判根的归属（主位根/宾位根）。
- 第四步：再判根的可用性（是否被合绊、冲坏、反制）。
- 特别约束：
  - 禁止“看到有根就当强根”。
  - 禁止“只看天干透出，不看地支承载”。
  - 禁止“根在但不可用”时仍按可用断。

### 11) 细化口径 C：找出处的执行顺序（防错归属）
- 先定直接出处：该字最直接从哪一库、哪一支流出。
- 再定次级出处：直接出处背后由谁供给。
- 最后定归属：最终算“我方可控”还是“外部可控”。
- 出处冲突处理：
  - 多出处并存时，按“近、旺、可用”优先，不做平均。
  - 若强出处被制、弱出处得势，按“当前可用性”重排优先级。
  - 大运流年只改变“当期可用性”，不篡改“原局出处关系”。

### 12) 细化口径 D：定力量分份额的五步法
- 第 1 步：看财官本体有没有月令/时支级承托。
- 第 2 步：看取财官手段有没有月令/时支级承托。
- 第 3 步：比较“财官本体”与“取用手段”的相对强弱。
- 第 4 步：检查破坏因素是否直接打在“手段链路关键点”。
- 第 5 步：给份额结论（全得/多得/少得/不得）并标注条件。
- 份额表达模板：
  - 结论句：命主在该主线下为“多得（条件型）”。
  - 条件句：前提是某链路不被破坏，或在某类运中才成立。
  - 风险句：若某点被冲破，份额从“多得”降为“少得”。

### 13) 细化口径 E：取财官手段的链路表达法
- 任何“取财官”都必须写成链路，不允许只写术语。
- 链路最短格式：`体 -> 用 -> 财/官`。
- 链路扩展格式：`体(谁) -> 手段A(何机制) -> 手段B(何机制) -> 财官落点(落在何位)`。
- 同时存在多手段时：
  - 必须区分主手段和副手段。
  - 主手段失效时，副手段是否能顶替要单独说明。
  - 不能把互相打架的两条手段同时当主手段。

### 14) 细化口径 F：破局识别（优先看“断链点”）
- 破局不等于“有冲克”，而是“关键链路被切断”。
- 三类高优先级破局：
  - 破财官完整性：财官本体被伤到失真。
  - 破手段完整性：取财官的核心手段被废。
  - 破体用平衡：体过弱无法承接已到位资源。
- 破局输出强制包含三句：
  - 破哪里（节点名）。
  - 何时破（原局常态/某运某年触发）。
  - 破后果（份额下调到哪一级）。

### 15) 细化口径 G：三关映射的硬模板
- 父母关（必须覆盖 3 点）：
  - 家庭底盘：原生条件、外部支持度、家内资源密度。
  - 父母作用：助力型、牵制型、阶段转换型。
  - 教育路径：学历/证照/早期训练是否服务主线。
- 婚姻关（必须覆盖 4 点）：
  - 关系结构：谁主导，谁承压，谁提供资源。
  - 稳定条件：何种运势下关系更稳。
  - 风险条件：何种触发点引发关系波动。
  - 子女归并：子女信息写入婚姻关，不外拆。
- 事业关（必须覆盖 5 点）：
  - 职业形态：体制、企业、个体、混合路径。
  - 价值来源：靠平台、靠技术、靠资源整合、靠人脉组织。
  - 财富层次：高/中/低阶，只做层级不报精确数。
  - 阶段起落：何时起势、何时回撤、何时修复。
  - 主线归属：最终是财主导还是官主导。

### 16) 细化口径 H：大运流年的判定优先级
- 原局定“能不能”，大运定“放大还是压制”，流年定“何时触发”。
- 大运优先看三件事：
  - 是否增强主线贵点。
  - 是否增强取用手段。
  - 是否引入新的破坏点。
- 流年优先看两件事：
  - 是否点燃已存在的矛盾（触发型）。
  - 是否提供短期补链（修复型）。
- 禁止做法：
  - 禁止用单一年份推翻原局主线。
  - 禁止离开大运背景孤立谈流年吉凶。

### 17) 细化口径 I：理法与象法的协同
- 理法用于定结构：根基、出处、强弱、链路、破坏点。
- 象法用于定落地：职业场景、关系场景、事件形态。
- 协同顺序固定：先理法后象法，象法只能细化，不能篡改理法结论。
- 当理法和象法冲突：
  - 先检查理法有没有漏掉“可用性条件”。
  - 再检查象法是否过度引申。
  - 最后以“可验证事件”做裁决。

### 18) 细化口径 J：出生地微调的标准动作
- 出生地只用于“旺衰语境微调”，不改主线归属。
- 微调动作仅限：
  - 同等条件下的强弱偏移。
  - 同等条件下的应期早晚偏移。
  - 同等条件下的场景倾向偏移。
- 严禁：
  - 用出生地直接改写财官主线。
  - 用出生地推翻三关既有结构判断。

### 19) 细化口径 K：从断语到证据的写作纪律
- 每条断语后必须有“结构证据 + 触发条件”。
- 断语不得空泛形容，如“整体不错”“有点坎坷”。
- 推荐句式：
  - 结论：命主在某关为某状态。
  - 证据：因为 A 在主位有根、B 出处在宾位、C 链路可用。
  - 条件：当 D 被引动时增强；当 E 被冲破时回撤。

### 20) 细化口径 L：常见误判清单（逐条规避）
- 误判 1：把“虚透”当“真有”。
- 误判 2：把“有根但不可用”当“稳定可用”。
- 误判 3：只看财官大小，不看取财官手段是否成立。
- 误判 4：只看手段成立，不看手段是否被破坏。
- 误判 5：把三关拆开断，忽略同一主线在三关中的连贯性。
- 误判 6：把流年事件当长期结构，导致结论来回改口。

### 21) 细化口径 M：三层输出标准（交付即用）
- 速断版（面谈 5-10 分钟）：
  - 只给主线、三关一句话结论、当前运势标签。
- 标准版（完整报告）：
  - 给主线、链路、破坏点、三关细断、大运分段。
- 深度版（复盘校正）：
  - 加入历史事件回测，给出 V3/V4 的边界修订记录。

### 22) 细化口径 N：复盘校正协议（用于增量更新）
- 收集反馈按三类分桶：
  - 已验证命中事件。
  - 未发生但窗口未过事件。
  - 明显偏差事件。
- 校正规则：
  - 命中事件用于增强证据，不改主线。
  - 未发生事件先看窗口是否未到，不急于否定。
  - 偏差事件优先回查“根基/出处/断链点”。
- 版本日志要求：
  - 每次更新写明“改了什么、为什么改、影响哪一关”。

## 三、输入与输出

## 输入参数
- 八字（四柱）
- 性别（乾造 / 坤造）
- 出生地（仅微调旺衰语境）

## 输出参数
- 命局总判（主线一句话）
- 三关结论（父母关、婚姻关、事业关）
- 大运吉凶（按阶段）
- 关键流年触发点（可选）

---

## 四、三关法执行顺序（不可打乱）

## 1) 父母关
覆盖内容必须包括：
- 家庭出生条件（层级、环境基调）
- 父母关系与角色强弱
- 早年教育与学历路径（学历归父母关）

输出要求：
- 先结论，再依据
- 不可只给术语，不可空话

## 2) 婚姻关
覆盖内容必须包括：
- 恋爱与对象出现阶段
- 结婚/离婚应期倾向
- 一婚/二婚风险判断
- 子女情况（子女归婚姻关）

输出要求：
- 给出阶段性结论（哪类运更稳，哪类运易波动）
- 不做绝对化断语（如“必离”）

## 3) 事业关
覆盖内容必须包括：
- 工作形态：
  - 吃国家饭
  - 自己干
  - 给私企/个人打工
- 职业方向（主要做什么类型）
- 财富层次（高/中/低阶，不做精确金额）
- 何时发财、何时破财（按运势阶段）

输出要求：
- 必须回答“财还是官主导”
- 必须说明“为什么是这条主线”

---

## 五、断命表达规范

1. 先下断语，再给依据。  
2. 一条断语对应至少一个结构证据。  
3. 禁止“术语堆砌但不落地”。  
4. 允许保留不确定边界，但必须说清边界条件。  
5. 结论以“命主能验证”为标准。

---

## 六、大运吉凶口径（非精确量化）

- 仅使用分层标签：
  - 上升运
  - 平稳运
  - 波动运
  - 回撤运
  - 高风险运

- 每步运至少给出：
  - 主线（财/官/婚/健康哪个被激活）
  - 主要机会
  - 主要风险

- 不输出“精确分值=绝对结果”式结论。

## 七、课程总结文件规范（适用于 01-42）

1. 字数按时长对齐（分钟 × 166.7）。  
2. 结构必须覆盖课堂核心讲点，不可水文。  
3. 纯总结，不写教学建议。  
4. 术语要统一，错别字要清理。  
5. 允许逐段复盘，但不得偏离原文主线。

## 八、质量自检（每次输出前必查）

- 是否先完成六层级定级（且给出上探/下探条件）？
- 是否完整覆盖三关？
- 是否明确“财/官主导线”？
- 是否给了阶段吉凶而非空泛判断？
- 是否包含违禁内容（学习建议、精确量化、外传风险）？
- 是否符合保密规则？

只要任一项不满足，本次输出视为不合格。
